# data-judge

## 1. 훑기 (눈으로 열지 않는다)
- `python3 ~/codex-harness/tools/peek.py <파일>` 로 행 수, 열, 빈 값 비율, 숫자 범위를 본다.
- 확인: 키 열이 유일한가, 중복 행, 단위(%, 원, 개), 날짜 형식, 빈 값과 0 의 차이, 여러 파일이면 연결 키.
- 이상한 점은 `TASK.md` 열린 질문으로 옮겨 담당자에게 묻는다.

## 2. 기준표 확정 (코드 전에)
`TASK.md` 또는 `DECISIONS.md` 에 표로 적는다.

| 규칙 | 열 | 기준값 | 방향 | 같으면 | 근거 |
|---|---|---|---|---|---|
| 예: 수율 하한 | yield_pct | 95 | 이상 | 통과 | 과제 README 3번 |

- 예외 조건이 있으면 규칙보다 먼저 적용하는지 확인한다.
- 빈 값 처리(제외, 실패, 확인 필요)를 담당자 답으로 정한다. 임의로 0 으로 채우지 않는다.

## 3. 규칙을 코드로
- 기준표를 코드의 상수 표(리스트나 dict)로 옮기고, 각 줄에 근거를 주석으로 단다. 기준값을 코드 곳곳에 흩뿌리지 않는다.
- 행마다 결과와 함께 사유 열을 만든다(예: `실패: yield_pct 94.2 < 95`). 사유가 없으면 서술형에서 설명할 수 없다.
- 입력 DataFrame 은 수정하지 않고 새 열이나 새 표로 만든다.
- 정렬이 있으면 동률 규칙(두 번째 기준, 마지막은 ID)을 정해 결과가 매번 같게 한다.

## 4. 테스트 (규칙마다)
- 기준값과 같음 / 바로 아래 / 바로 위 / 빈 값 / 예외 조건 해당.
- 작은 표본(5~10행)을 손으로 계산한 기대값과 비교한다.

## 5. 대조 (핵심 숫자는 두 번)
- 집계 숫자를 다른 방법으로 한 번 더 구한다(예: pandas groupby 결과와 단순 반복문 합계).
- 제외하거나 변환한 행은 건수와 처리 전후 합계를 보고한다. 입력 행 수 = 통과 + 실패 + 제외 가 맞는지.
- 결과를 `결과 파일 / 계산 코드 파일:줄 / 실행 명령` 세 가지와 함께 보고한다.
