# verify

말이 아니라 실행 결과로 확인한다. 각 항목에 실행한 명령과 결과를 붙인다.

1. 테스트 전체 실행. 실패가 있으면 멈추고 보고.
2. 과제가 요구한 방식 그대로 실제 실행(샘플 입력, 스크립트, 서버). 출력을 보여준다.
3. `TASK.md` 인수 기준을 하나씩 대조해 표로: 기준 / 확인 방법 / 결과(통과, 실패, 미확인).
4. 제출물 형식: 파일명, 경로, 출력 형식, 필요한 실행 방법 안내(README 나 제출란).
5. 정리: `git status` 가 깨끗한지, 디버그 출력, 임시 파일, 비밀값이 남지 않았는지.
6. `DECISIONS.md` 에 빠진 결정이 있으면 채운다.

## 출력
```
통과: N / 실패: N / 미확인: N
미확인과 실패는 이유와 남은 위험을 한 줄씩.
```
