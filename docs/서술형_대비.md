# 서술형 대비 (AI 없이, 문항당 5분)

예상 질문은 평가 관점(문제 정의 / AI 활용 / 결과 검증)에서 뽑은 추측이다. 실제 문항은 모른다.

## 답 틀 (3문장)
1. 무엇을 했나(결론 먼저)
2. 왜 그렇게 했나(근거, 버린 대안)
3. 어떻게 확인했나(테스트, 실행 결과, 숫자)

## 예상 질문
- 과제를 어떻게 이해했고, 무엇을 가정했나?
- AI 에게 일을 어떻게 나눠 맡겼나? 맡기지 않고 직접 판단한 것은?
- AI 가 틀린 답을 낸 적이 있나? 어떻게 알아챘고 어떻게 고쳤나?
- 결과가 맞다는 것을 어떻게 검증했나?
- 시간이 더 있었다면 무엇을 했겠나? 지금 남은 위험은?
- 가장 어려웠던 결정과 그 이유는?

## 연습
- 오늘 밤 모의 과제 하나를 끝낸 뒤 위 질문 3개에 타이머 5분으로 손으로 답해 본다.
