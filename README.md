# codex-harness

Codex 로 시간 제한 개발 과제를 할 때 쓰는 개인 작업 지침과 스킬.

- `AGENTS.md`: 작업 원칙 (Codex 가 자동으로 읽음)
- `.agents/skills/`: dev-flow, systematic-debugging, review-checklist, verify
- `RUN.md`: 당일 운영표
- `TASK.md`, `DECISIONS.md`: 과제 계약과 결정 기록 템플릿
- `docs/서술형_대비.md`

사용: `git clone` 후 저장소(또는 과제 폴더로 복사한 위치)에서 `codex` 실행. 자세한 순서는 `RUN.md`.

라이선스: MIT. `systematic-debugging` 은 obra/superpowers-skills (MIT) 를 각색함.
