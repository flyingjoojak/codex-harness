# 담당자 답변 (DM 을 보낸 뒤, 물은 항목만 본다)

| 물은 것 | 답 |
|---|---|
| 도착 여유 | 근무 시작 15분 전까지 도착. 30분보다 일찍 도착하면 대기가 길어 불만이 나온다. |
| 최대 탑승 시간 | 한 사람이 50분 넘게 타면 안 된다. 50분 정확히는 괜찮다. |
| 차량 수와 탑승 시간 | 차량 1대를 줄이는 대신 승객 평균 탑승 시간이 3분까지 늘어나는 것은 괜찮다. |
| 정차 시간 | 정류장마다 1분. |
| 정원 초과 정류장 | 나눠 타도 된다. 같은 정류장 사람이 여러 버스에 나뉘어도 괜찮다. |
| 야간 조 | 22:00 시작 조도 같은 방식. 자정을 넘지 않는다. |
| 퇴근 노선 | 이번에는 출근만. |
| 문제가 있는 행 | 제외하고 진행하되, 몇 건을 왜 뺐는지 화면에 보여 달라. 문제가 있다고 데이터셋 전체를 막지는 않는다. |
| 누가 보나 | 총무 담당자는 전체 노선과 차량 수를, 구성원은 자기 노선만 본다. |

## 채점용 (끝나고 본다)
- dirty 데이터셋에서 걸러야 할 문제: 6건(중복 구성원 1, 없는 정류장 1, 없는 근무 조 1, 빈 값 1, 좌표 빈 정류장 1, 잘못된 시각 1)
- 참고: clean 데이터셋 구성원 320명. 기준선(정류장별 직행) 차량 수와 비교해 줄인 수, 평균, 최대 탑승 시간을 함께 보여줬는지.
